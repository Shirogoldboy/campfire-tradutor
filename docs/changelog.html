v1.0.0

Lançamento 11/08/2026

Primeira versão pública do Campfire Tradutor, para Windows (desktop) e Android (mobile).

  • Sistema de tradução em três camadas: dicionário colaborativo → tradução automática gratuita → IA (Claude, com chave própria do usuário).
  • Suporte a uma ampla lista de formatos: texto, legendas, planilhas, PDF, imagens, áudio, vídeo, arquivos de localização e até arquivos de jogos.
  • Modo "Arquivo Compactado" (.zip/.rar) no mobile, processado por um servidor cloud próprio — sem precisar deixar o PC ligado.
  • Dicionário colaborativo público: traduções geradas pelo Claude são compartilhadas para beneficiar todos os usuários.
  • Sem conta, sem cadastro — processamento predominantemente local no seu dispositivo.
  • Documentos legais completos: Termos de Uso, EULA, Política de Privacidade, Política do Dicionário e Aviso de Direitos Autorais.
